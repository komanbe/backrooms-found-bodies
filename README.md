# Backrooms(Found Bodies) 展覧会特設サイト

黒瀬陽平によるステートメントを中核にした、1ページ縦スクロール完結型の展覧会サイト。
デザインコンセプトは「**検死降下**」——読み進めるほど、蛍光灯の白（GF）から闇（B3F）へ沈んでいく。

公開URL: https://komanbe.github.io/backrooms-found-bodies/

## 構成

```
├── index.html        # 全部入り（CSS/JSインライン、依存なし）
└── assets/img/       # 写真14点（Web最適化済み）
```

- **ビルド不要・依存なし**。任意の静的ホスティングにそのまま置けば動きます。
- ローカル確認: `python3 -m http.server 8931` → http://localhost:8931

## ページ構造（深度）

| 深度 | セクション | 背景 |
|------|-----------|------|
| GF   | ヒーロー（3D廊下）／ステートメント Ⅰ | `#F4F2EE`（蛍光灯の白） |
| B1F  | 写真 No.01–02／ステートメント Ⅱ | `#DFDBD3` |
| B2F  | 写真 No.03–04／ステートメント Ⅲ・署名 | `#34322E` |
| B3F  | 記録（No.05–13）／註／No.14（ボタン）／開催概要 | `#101012` |

背景はスクロールに連動して章の切れ目（写真インタールード）でのみ遷移します。
JS無効時は各セクションが固定の背景色を持つ静的フォールバックになります。

## タイポグラフィ（Google Fonts）

- 本文: **Zen Old Mincho** 400（暗部は500）／17.5px（SP 16px）／行送り2.05／全角36字組・両端揃え
- 見出し: Zen Old Mincho 900、英文: **EB Garamond** 500
- 註・キャプション・実務情報: **Noto Sans JP** 300–500（「批評の声／事務の声」の書体分離）
- 深度表示（GF/B1F…）: **Kaisei Tokumin** 800（`&text=`サブセット読み込み）

## 演出（すべて prefers-reduced-motion で無効化）

- ファーストビュー: **CSS 3Dの「無限に歩き続ける黄色い廊下」**（ライブラリ不要。グラデーションで壁・床・天井を描画し、テクスチャの流れで歩行を表現。マウスで視線がわずかに動く）
- タイトルが時折、切れかけの蛍光灯のように瞬く
- 初回アクセス時のみ「蛍光灯が点く」フリッカー（sessionStorage で1回制御）
- 背景全体に、光の染みがゆっくり漂い、ごく稀に一瞬暗くなる「揺らぎ」
- 写真のフェードイン、右下の深度計のごく稀な明滅
- No.14 のボタンは、押しても何も起こりません（仕様です）

## 写真について（重要）

`assets/img/` の写真は **EXIF（GPS位置情報・撮影日時・機種名）を完全に除去済み** です。
会場非公開の展覧会のため、元フォルダ（HP用写真/）のファイルをそのままWebに上げないでください。
新しい写真を追加する場合も同様に、メタデータを除去してから配置してください（回転もベイクすること）。

※No.06「案内図」は画面内に地名が読める写真です。会場のヒントになり得る場合は差し替え・削除を検討してください。
