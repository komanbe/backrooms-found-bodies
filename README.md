# Backrooms(Found Bodies) 展覧会特設サイト

黒瀬陽平によるステートメントを中核にした、1ページ縦スクロール完結型の展覧会サイト。
全編白背景（#F4F2EE）のミニマル構成。

公開URL: https://komanbe.github.io/backrooms-found-bodies/

## 構成

```
├── index.html        # 全部入り（CSS/JSインライン、依存なし）
└── assets/img/       # 写真20点（ヒーロー1点＋HP写真再選定19点、Web最適化済み）
```

- **ビルド不要・依存なし**。任意の静的ホスティングにそのまま置けば動きます。
- ローカル確認: `python3 -m http.server 8931` → http://localhost:8931
- 更新は このフォルダで commit → `git push origin main`（GitHub Pages が自動反映）

## ページ構成

1. **ファーストビュー** — 写真を原寸比率のまま表示し、左下に一行タイトル（スクロールでサイズは変わらない）
2. **ステートメント＋写真** — 「HP写真再選定」の19点を番号順に本文の合間へ織り込み。暗い3点（ぶれた廊下・夜の階段・海）には本文を白文字で重ねる
3. **注釈（1）〜（3）と署名** — 原稿の順序どおり
4. **開催概要** — 目録体裁の行リスト

ヘッダー・メニュー・フッターの導線・深度計・背景の暗転などのUI/演出は一切なし。

## タイポグラフィ（Google Fonts）

- 本文: **Zen Old Mincho** 400／17.5px（SP 16px）／行送り2.05／全角36字組・両端揃え・書籍式字下げ
- タイトル: **Noto Sans JP** 200（細く・丸みのない角ゴ・字間広め）
- 注釈・概要: Noto Sans JP 300–500、英字: EB Garamond

## 残っている演出（すべて prefers-reduced-motion で無効化）

- タイトルが時折、切れかけの蛍光灯のように瞬く
- 初回アクセス時のみの点灯フリッカー（sessionStorage で1回制御）
- 背景をごくゆっくり漂う光の染み

背景の暗転・写真のフェードイン・ズーム等は削除済み。

## 写真について（重要）

`assets/img/` の写真は **EXIF（GPS位置情報・撮影日時・機種名）を完全に除去済み** です。
会場非公開の展覧会のため、元フォルダ（HP用写真/・HP写真再選定/）のファイルをそのままWebに上げないでください。
新しい写真を追加する場合も同様に、メタデータを除去してから配置してください（回転もベイクすること）。
